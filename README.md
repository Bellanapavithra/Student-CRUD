# Student Database CRUD Application

## Project Description
This project is a Student Database CRUD Application developed using Python, FastAPI, and SQLite.

It allows users to create, view, update, and delete student records through a REST API.

## Technologies Used
- Python
- FastAPI
- SQLite
- Uvicorn
- Swagger UI

## Features
- Add student details
- View all students
- Search students
- View a student by ID
- Update student details
- Delete student records

## How to Run
1. Install the required packages:
   `pip install -r requirements.txt`

2. Start the application:
   `python -m uvicorn main:app --reload`

3. Open Swagger UI:
   `http://127.0.0.1:8000/docs`
